# Remembering Arc

An open-source Chrome extension that brings Arc-style Spaces and a vertical sidebar to Chrome, synced across devices through Chrome bookmarks. (Working name: the product will be renamed before release.)

## Language

### Organizing tabs

**Space**:
A named, switchable collection of Pinned tabs, Folders and Today tabs. The sidebar shows one Space at a time.
_Avoid_: Workspace, profile, tab group

**Active Space**:
The Space a window is currently showing. Each window has its own.
_Avoid_: Current Space, selected Space

**Pinned tab**:
A saved entry in a Space that stays in the sidebar whether or not its page is open.
_Avoid_: Bookmark, saved tab, Chrome-pinned tab

**Pinned URL**:
The address a Pinned tab opens and returns to. Navigating inside the open tab doesn't change it.
_Avoid_: Home URL, saved URL

**Folder**:
A named group of Pinned tabs and other Folders inside a Space.
_Avoid_: Bookmark folder, group

**Favorite**:
A saved entry shown in every Space, as an icon above the Space's contents.
_Avoid_: Global pin, shortcut

**Today tab**:
An open tab in a Space that isn't a Pinned tab or a Favorite. It exists only on the device where it was opened.
_Avoid_: Unpinned tab, loose tab, temporary tab

**Archive**:
Where Today tabs go when they close themselves after sitting idle.
_Avoid_: History, trash

**Chrome-pinned tab**:
A tab that Chrome itself has pinned to the far left of its tab strip. Not the same thing as a Pinned tab.
_Avoid_: Pinned tab, native pin

### The sidebar

**Auto-hide**:
The sidebar mode where the sidebar stays hidden until the mouse reaches the window's edge, then slides over the page.
_Avoid_: Overlay mode, hover mode, collapsed

**Docked**:
The sidebar mode where the sidebar stays open beside the page.
_Avoid_: Side panel, pinned sidebar, expanded
